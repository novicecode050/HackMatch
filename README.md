# 🚀 HackMatch — Hackathon Teammate Compatibility Engine

A niche student management system designed to pair hackathon participants into balanced teams based on complementary tech stacks (Frontend, Backend, ML, DevOps) and availability.

## 🛠️ Tech Stack & DevOps Pipeline
* **Application**: Node.js, Express.js
* **Testing**: Jest & Supertest
* **Version Control**: Git & GitHub
* **CI/CD Automation**: Jenkins Pipeline
* **Containerization**: Docker & Alpine Linux
* **Orchestration**: Kubernetes (Deployment & ClusterIP Service)

---

## 📌 API Endpoints
* `GET /health` - Service health check
* `POST /api/hackers` - Register a hacker profile and tech stack
* `POST /api/teams/form` - Trigger algorithmic team formation
* `GET /api/teams` - List all active hackathon squads
